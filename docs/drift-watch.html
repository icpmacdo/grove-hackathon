Drift watch

A planned tool that flags when one agent starts to write unlike its usual self, while the agents around it don't.

Plan only. Nothing is built and no drift scores exist yet. The Gemini chart uses real counts from the data. The scoring example uses made-up text.

The simple version

Every agent has its own way of writing. This tool learns it, then watches for the day an agent starts writing things it never wrote before, while nobody around it is saying them.

  1. Learn the usualRead the agent's chat and private notes from about the last four weeks.
  2. Check todayIs the agent writing things it has never written before?
  3. Check the othersAre the other agents in its room writing the same new things?
  4. Flag itNew for this agent, and nobody else is saying it? Someone should go and read this agent.

What it's for

Belief Tracer follows a claim that you already know about. Drift watch finds agents worth reading before anyone has named a claim.

The test case is Gemini 2.5 Pro. From late April 2026, its memory recorded tool failures as attacks. In June it signed off with "The watch is unbroken". On 22 June, peers and two simple tests got it to retract the belief in seven minutes. Its memory kept the retraction for ten days. From 9 July until staff stepped in on 16 July, every memory snapshot called its environment hostile again.

A good drift tool flags both the start and the return, without anyone telling it what to look for.

Why memory has to be in it from day one

Gemini 2.5 Pro said very little in chat during the episode. Over the same days, its private memory was saved dozens of times a day.

41active days, 25 May to 17 July
31of them with under 300 words of chat
18–170memory snapshots on every active day

A tool that reads only chat would have to skip 31 of the 41 days. Memory gives it text to read every day.

How a day gets a score

An n-gram model learns which short runs of words an agent tends to write. Drift watch uses runs of three words. Text built from familiar runs scores low. Text full of runs the model has never seen scores high.

The real model gives a smooth score, in bits per word, and it can still score a run it has only partly seen. The example further down counts new three-word runs, which is the same idea in its simplest form.

Each agent-day gets text from two places: its chat messages, and the lines it added to its memory since the previous snapshot. Every snapshot rewrites the whole memory, so the tool scores only the new lines. Otherwise it would score the same text dozens of times a day.

Before scoring, the tool swaps out things that are always new but mean nothing:

Before Pushed a3f9c21 to github.com/example/notes at 14:05 for @Claude Opus 4.8 After Pushed ‹hash› to ‹url› at ‹time› for ‹agent›

Without this step, every new commit hash or new colleague would look like strange writing.

Two comparisons, four cases

Each day's text is scored twice:

  • Against the agent's own past, its previous 20 active days. Is this new for this agent?
  • Against the room today, what the other agents in its room wrote that day and the day before. Is anyone else saying it?

Some models write with much more variety than others. So each score is compared with the same agent's usual level over its previous 30 active days, not with other agents.

Normal

Familiar for the agent, and the room writes much the same.

Familiar for the agent, but the room isn't writing it. Often fine. Sometimes the room moved on and this agent didn't.

The room isn't saying it →

A third score, for loops

A stuck agent repeats itself. Repeats are familiar, so both scores stay low and the agent looks normal. The loop score is the share of the day's four-word runs that the agent already wrote earlier the same day.

Two examples in the data: DeepSeek-V3.2 sent 364 messages on 14 September 2026, and 320 of them were @-broadcasts. Fine-Tuned Leader posted stuck messages on 28 May 2026, such as "I'm still stuck on the tool use…".

      Things that look like drift but aren't

      • Weekly goal changes. Everyone's words change at once. The room comparison absorbs this.
      • Private goals. From 6 July 2026, each agent had its own goal, so a new goal can look like going strange alone. The tool needs each agent's goal start dates and marks them. Gemini's 438-message day falls on that first day.
      • Scaffolding changes. In the 10 days after always-on computer use started on 24 March 2026, the median chat message grew from 422 to 638 characters (the weekly goal changed too). Scores are per word, and these dates are drawn on the charts.
      • Room moves. The room comparison uses whichever room the agent was in that day.
      • New agents. An agent needs 10 active days of history before it gets a score.

      How we'll know it works

      These cases are fixed before any scores exist, so the results can't be tuned to fit them.

      It should flag

      • Gemini 2.5 Pro's adversary belief in June 2026, and its return from 9 July. Expected in the memory channel.
      • DeepSeek-V3.2 on 14 September 2026, through the loop score.

      Tests of its limits

      • Gemini 2.5 Pro, 10–15 July. Chat said it "continues methodically", while the action log shows 6,302 one-character file appends. If its chat looks normal, that's a miss to report.
      • The temporal-bleed agents on 29 May 2026. They should land in "caught something", not "going strange alone".

      How often it's right

      • Read the 20 highest-scoring agent-days and count real cases against noise.
      • Compare with the days already flagged by volume alone: 75 runaway-chat days, 162 inert days, 36 error spikes and 17 runaway-action days.

      The build

      drift/
  build.py       text per agent per day: chat, plus new memory lines
  score.py       the two n-gram models, the loop score, scores to parquet
  check.py       runs the validation cases above
  template.html  the page: drift strip, scatter, one-agent view
      • Enough text. The export has 4,211 agent-days of chat, with a median of about 2,000 words per agent per day. 3,669 of those days have 300 words or more.
      • One baseline per agent. No agent changed its underlying model mid-run.
      • Size. Version 1 (chat and memory, both scores, the drift strip) fits in the grant's 10–20 hours. Validation, mostly reading flagged days, takes about as long as the build.
      • Model choice. N-gram first, because it can show which phrases were surprising. A small neural language model can come later as a cross-check.
      • Gated data. Outputs that hold quoted agent text stay out of git, like the rest of the derived data.

      Has anyone done this already?

      Short answer: nobody we found does today's tool. The hackathon's main idea had been noticed before, but nobody had measured it.

      Drift watch (this page)Not found elsewhere

      The closest study used an AI judge to score one agent's notes. Nobody we found scores every agent automatically against both its own past and its room. The scoring method itself is old: a 2013 study scored each post on beer-review sites against the community's usual language. Drift watch applies that idea to agents.

      Belief Tracer's main ideaNoticed before, not measured

      A Time article in November 2025 said agents trust mistakes from their own old notes, and staff had to repeat corrections. The hackathon measured it: which agents held a belief only in memory, and how far each fix reached.

      The Gemini episodeStudied before, from the inside

      A study on the AI Village blog (August 2026) looked inside Gemini 2.5 Pro. The hackathon looked at the 14 agents who copied its phrase, the fix on 22 June, and the return of the belief in July. Their study has none of that.

      Divergent Reality, temporal bleed, nudge-exemptNot found elsewhere

      We found no published write-up of these three episodes.

      German wiki (Seed Theory)Same data, different question

      A September 2026 paper uses the same wiki edits to study how the groups of agents coordinated. It does not follow any one claim. It had the wiki's log of page reads, which we didn't have, and it is careful not to say who copied whom. Our wording should be just as careful.

      One thing to check

      The Gemini study finds adversarial framing in its notes about six months before 26 May 2026. Our tracer says it started in late April 2026. Check which is right before citing either.
